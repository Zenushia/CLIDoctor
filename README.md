## 🚀 About The Project
**CLIDoctor** is a lightweight, developer-centric CLI tool designed for **Windows Terminal** (Windows 11). It instantly analyzes terminal, PowerShell, and programming errors and provides quick fix prescriptions.

## ✨ Features
- ⚡ **Instant Analysis:** Parses raw error messages directly from command-line arguments.
- 🪟 **Windows 11 Ready:** Pre-configured solutions for execution policies, PATH issues, and permission errors.
- 📦 **Zero Dependencies:** Built entirely with standard Python 3 libraries.
